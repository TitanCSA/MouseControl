MouseControl 1.0.1 - Windows 10/11 x64
https://github.com/TitanCSA/MouseControl

1. Extract the complete ZIP.
2. Open InterceptorSetup.exe, choose Install / reinstall, and restart Windows
   only if requested. This is the Keyboard & Mouse edition.
3. Open MouseControl.exe and accept administrator approval.
4. Click outside its window and hold the left mouse button.

Default: wait 30 ms, then repeat move(-100), with an 8 ms loop gap.
Negative vertical values move down. Counts are not guaranteed screen pixels.
Release the trigger to stop. Click Pause, or use Ctrl+Alt+F12, to release capture.
Actions are suspended while the MouseControl window is active.

Use Visual to change/add/reorder steps, or Code to edit the same sequence.
Select multiple trigger buttons/keys to require all of them together.
Settings save automatically; there is no Apply button.

The Interceptor Keyboard & Mouse driver demo allows one hour per Windows kernel
boot, shared with other applications using that edition. Windows Restart begins
a new allowance. For the full driver without this limit, add titancsa on Discord.
